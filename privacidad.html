2. Funcionamiento de las calculadoras

Las calculadoras de esta versión están diseñadas para realizar operaciones mediante JavaScript en el navegador del visitante.

El proyecto no necesita enviar los números introducidos a un servidor propio para realizar estos cálculos.

3. Preferencias locales

La web utiliza el almacenamiento local del navegador para recordar la preferencia de modo claro u oscuro. Esta información permanece en el navegador y puede eliminarse desde su configuración.

4. Alojamiento de la web

Este sitio está alojado mediante GitHub Pages, un servicio de GitHub. Como proveedor de alojamiento, GitHub puede tratar información técnica necesaria para ofrecer el servicio, como direcciones IP y registros de acceso, conforme a sus propias condiciones y políticas.

Consulta la información de privacidad de GitHub.

5. Contacto por correo electrónico

Si envías un correo electrónico al proyecto, se tratarán la dirección del remitente y los datos incluidos en el mensaje para gestionar y responder la consulta.

Antes de publicar esta política como definitiva, deben concretarse la base jurídica, los plazos de conservación, los posibles destinatarios y los derechos aplicables.

6. Publicidad y herramientas de análisis

Esta plantilla corresponde a una versión sin integración propia de Google AdSense ni herramientas de análisis de visitantes.

Si se incorporan anuncios, estadísticas u otros servicios externos, se actualizará esta política y se implementarán los mecanismos de información y consentimiento que correspondan.

7. Derechos de protección de datos

Las personas interesadas pueden solicitar información sobre el tratamiento de sus datos y ejercer los derechos que les correspondan conforme a la normativa aplicable, mediante el correo de contacto indicado.

En España, la Agencia Española de Protección de Datos ofrece información sobre estos derechos en aepd.es.

8. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funciones del sitio, los proveedores utilizados o los requisitos legales aplicables.
